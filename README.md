# Portfólio Profissional - 2026

Este é o meu portfólio desenvolvido com **Next.js**, **Node.js** e **CSS moderno**. 
O objetivo é apresentar minha trajetória acadêmica e profissional, além dos projetos que desenvolvi.

## Tecnologias Utilizadas
- **Frontend**: React, Next.js, Tailwind CSS / CSS3.
- **Backend**: Node.js (API Routes do Next.js).
- **Integrações**: CallMeBot API (WhatsApp).

## Funcionalidades
- [x] Efeito de Glow interativo que segue o mouse.
- [x] API de contato direto via WhatsApp.
- [x] Layout responsivo (Desktop e Mobile).
- [x] Seções de Experiência Acadêmica e Profissional.
